Make a bootable USB stick from your browser

Project mkstick puts a Windows or Linux installer on a USB stick with nothing to install. It does the job of an app like Rufus and works the same way on Windows, Mac and Linux.

Make a stick How it works

Free and open source, by Conan Zhang.

#projectmkstickbycztsh

  • A USB stick of 8 GB or more, or 16 GB for Windows
  • Chrome or Edge on a computer
  • About ten minutes for most installers

This browser can't write to a USB stick. Safari, Firefox and phone browsers don't allow a web page to save files to a drive, so please open Project mkstick in Chrome or Edge on a computer. You can still click through the steps here to see how it works.

  3. Choose your stick

    Plug the stick in and press the button below. A window opens showing your drives, where you click the stick in the list on the left and then press Select. Your browser will ask whether Project mkstick may edit files on it, and you need to allow that.

    The stick has to be empty and in FAT32 format, which most sticks of 32 GB or less already are. Project mkstick only adds files and has no way to delete what is on a drive.

    My stick isn't empty, or isn't FAT32

    Formatting the stick fixes both, but it erases everything on the stick, so copy off anything you want to keep first. A web page isn't able to format a drive, which is why this part is done by you. If the stick was giving errors, eject it, unplug it and plug it back in before you start.

    1. Open File Explorer, right-click the stick and choose Format.
    2. Set the file system to FAT32 and press Start.
    3. If FAT32 isn't in the list, which happens with sticks over 32 GB, open Command Prompt and run the line below with E: changed to your stick's letter. This needs Windows 11 version 24H2 or later.
    format E: /FS:FAT32 /Q
    1. Open Disk Utility and choose Show All Devices from the View menu.
    2. Select the stick itself, which is the top entry rather than the volume beneath it, and press Erase.
    3. Set the format to MS-DOS (FAT) and the scheme to Master Boot Record, then press Erase.
    1. Open Disks, select the stick and choose Format Disk with MBR partitioning.
    2. Add a single partition of type FAT.
    3. If you prefer a terminal, run the line below with sdX1 changed to your stick's partition.
    sudo mkfs.vfat -F 32 /dev/sdX1

    Starting a PC from it

    Eject the stick before you unplug it. Then plug it into the PC, switch the PC on and press its boot menu key straight away, before Windows starts. Choose the stick from the menu, and if it appears twice, choose the entry marked UEFI.

    The boot menu key depends on who made the PC
    MakerKey
    DellF12
    HPF9 or Esc
    LenovoF12
    AsusF8 or Esc
    AcerF12
    MSIF11

    The stick starts PCs that use UEFI, which covers nearly every PC made since 2012.

    How it works

    A modern PC can start from a USB stick that simply holds the installer's files, as long as the stick is in FAT32 format. Project mkstick opens the installer's disc image and copies each file across. Windows includes one file that is too big for FAT32, so Project mkstick splits it into parts that Windows Setup puts back together by itself.

    Windows comes from Microsoft through your own browser, while Ubuntu and Debian are fetched from their publishers and checked against the checksums they publish. Project mkstick keeps no copies of any of them.

    The full documentation is on czt.sh, and the source code is on GitHub.

    Is it safe?

    Project mkstick can only add files to the folder you point it at, because a web page has no way to format or erase a drive, and it refuses to write to a folder that already has things in it. The installer file you choose is read on your own computer and never sent anywhere. The code is open source, so anyone can check all of this.

    What it can't do

    It needs Chrome or Edge on a computer, since other browsers don't let a page write to a drive. The sticks it makes start UEFI PCs, which leaves out some machines from before 2012, and it can't make Mac installers.
